### // SOBRE O PROJETO

**Terminal Override // Sentinel** é um dossiê interativo desenvolvido para uma campanha de RPG de mesa que combina os universos de **Matrix** e **Mago: A Ascensão**.

Ambientado em uma Nova York simulada de 1999, o site representa o terminal pessoal de **Blaze “Sentinel” Thorne**, uma Adepta Virtual integrante da cabala Anonymous. O terminal funciona como um arquivo em constante expansão, reunindo suas descobertas, seu paradigma mágico, equipamentos, aliados e contatos da resistência.

Os registros narrativos são apresentados sob uma perspectiva interna ao universo da campanha, interpretando a realidade por meio da programação, da segurança digital e da manipulação de sistemas.

### // FUNCIONALIDADES DO SISTEMA

- Interface retrô inspirada em monitores CRT, com linhas de varredura e efeitos de distorção.
- Estética hacker inspirada em Matrix, com elementos neon.
- Retratos biométricos e diagramas técnicos vetoriais em SVG.
- Modo Paradoxo interativo com alterações cromáticas.
- Dossiês narrativos e registros pessoais de Sentinel.
- Console fictício com comandos funcionais.
- Interface responsiva para computadores e dispositivos móveis.
- Banco de dados expansível conforme o desenvolvimento da campanha.
